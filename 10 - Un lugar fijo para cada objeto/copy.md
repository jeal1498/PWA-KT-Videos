## Texto para Instagram y Facebook

Un lugar fijo para cada objeto.

Si pierdes constantemente tus llaves, tu cartera o tus audífonos, prueba estos tres cambios:

1. Asigna un lugar fijo a cada objeto. Un espacio específico para cada cosa, en lugar de una zona general donde todo termina amontonado.
2. Haz que ese lugar sea visible y cómodo. Si tienes que abrir tres cajones para guardar algo, es posible que el sistema sea demasiado complicado para tu rutina.
3. Crea una pequeña revisión antes de salir. Pregúntate «¿qué tengo?»: las llaves, el celular, la cartera y lo que necesitas para la siguiente actividad. Puedes colocar una lista cerca de la puerta para no tener que recordar cada elemento desde cero.

Un detalle importante: si cambias de lugar tus objetos constantemente, el sistema pierde parte de su utilidad. Mantén el mismo punto de referencia durante varios días y observa si te ayuda.

Estas ideas pueden beneficiar a muchas personas, tengan o no TDAH. No son una prueba diagnóstica ni una solución universal.

Guarda este video y elige un objeto al que le vas a asignar un lugar fijo hoy.

Karen Trujillo, Neuropsicóloga Clínica
psicologakarentrujillo.com.mx
