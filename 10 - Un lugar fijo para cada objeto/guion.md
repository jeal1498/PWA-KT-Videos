# Guion: Un lugar fijo para cada objeto

Origen: `v10` de la carpeta de Drive. Mismo tema que el 08 y el 09 (objetos que se pierden), con otro guion y otros ejemplos. Texto aprobado por Eduardo el 23 oct 2026.

## Transcripción corregida

Si pierdes constantemente tus llaves, tu cartera o tus audífonos, prueba estos tres cambios.

Uno. Asigna un lugar fijo a cada objeto. No una zona general donde termina todo amontonado, sino un espacio específico para cada cosa.

Dos. Haz que ese lugar sea visible y cómodo. Si tienes que abrir tres cajones para guardar algo, es posible que el sistema sea demasiado complicado para tu rutina.

Tres. Crea una pequeña revisión antes de salir. Pregúntate, ¿qué tengo? Las llaves, el celular, la cartera y lo que necesito para la siguiente actividad. Puedes colocar una lista cerca de la puerta para no tener que recordar cada elemento desde cero.

Y un detalle importante, si cambias de lugar tus objetos constantemente, el sistema pierde parte de su utilidad. Intenta mantener el mismo punto de referencia durante varios días y observa si te ayuda.

Estas ideas pueden beneficiar a muchas personas, tengan o no tengan TDAH. No son una prueba diagnóstica ni una solución universal.

Guarda este video y elige un objeto al que le vas a asignar un lugar fijo hoy.
