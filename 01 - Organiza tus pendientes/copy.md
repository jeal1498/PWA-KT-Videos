## Texto para Instagram y Facebook

Deja de confiar en tu memoria.

3 formas de organizar tus pendientes:

1. Usa un único lugar para anotarlos: una libreta, una app o una lista en tu celular.
2. Convierte cada pendiente en una acción concreta. En lugar de «hacer trámites», escribe «buscar los documentos para el trámite».
3. Si algo tiene un horario específico, configura una alarma con información útil: «salir de casa para la cita», con el tiempo que necesitas para llegar.

Estas herramientas pueden servir a muchas personas, incluidas algunas con TDAH. Cada quien necesita un sistema que pueda mantener. Si olvidas el tuyo, hazlo más visible o más sencillo.

Guarda este video y elige una estrategia para probarla esta semana.
